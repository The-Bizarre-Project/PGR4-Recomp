# About this project
* PGR4-Recomp is a project that intends to port Project Gotham Racing 4 to PC. All of this is possible, thanks to the [ReXGlue SDK](https://github.com/rexglue/rexglue-sdk), allowing us to convert meaningless PowerPC code to C++ so our modern day computers can understand.
* Now, you may be wondering, "What inspired the people behind this project to make this recompilation of Project Gotham Racing 4?", and to put it simply, we love the game, seriously. It was one of the first ever racing games some of us ever played, so we wanted to keep it as alive as possible!
